# Audiolivros

Envie um PDF, escolha o capítulo ou as páginas e o servidor gera o MP3 (voz Edge ou Gemini),
já sem números de página, cabeçalhos, rodapés e notas, e com as referências bíblicas lidas por extenso.
O player tem ±5/±10 segundos, velocidade até 3× e lembra onde você parou.

Variáveis de ambiente:
- `APP_SENHA`: senha para abrir o app.
- `GEMINI_API_KEY` (opcional): libera a voz do Gemini.
